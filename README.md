# MassUp V3

Prototype web 16+ orienté prise de poids progressive, nutrition, musculation, suivi et coach.

## V3
- Onboarding 16+ et mode croissance 16–17
- Tableau de bord
- Estimation calories/macros pour adultes
- Pour 16–17 ans : pas de cible calorique rigide
- Plan musculation adapté à l'âge, sans 1RM/maximal en solo
- Journal repas et macros
- Suivi du poids
- Suivi des séances
- Coach avec garde-fous croissance
- PostgreSQL / Render
- UI responsive

## Render
Variables:
- DATABASE_URL = Internal Database URL de PostgreSQL
- JWT_SECRET = secret généré
- OPENAI_API_KEY = optionnel, uniquement côté serveur

## Santé
L'application est un outil d'organisation, pas un dispositif médical. Chez les mineurs, les besoins énergétiques dépendent notamment de la croissance et du développement. Pour toute inquiétude concernant poids, croissance, douleur, fatigue ou alimentation, demander conseil à un parent/tuteur et à un professionnel de santé.
